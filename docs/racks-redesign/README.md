# Racks style redesign

The design handoff for the iPhone and Mac redesign, filed as beads under the epic "Racks style redesign (iOS and Mac) Spec".

- `HANDOFF.md`: the spec: navigation, screens, tokens, components, behaviour, open decisions.
- `DesignTokens.swift`: the colour, type, spacing and radius tokens as Swift.
- `ios-mockups/`, `desktop-mockups/`: each screen as HTML; read their inline styles for exact sizes, colours and copy. They need the canvas's design runtime and do not render on their own.
- `comps/`: a PNG render of each mockup at 2x (iPhone 393×852 pt, desktop 1440×900 pt). Each bead's design field names its comps.
