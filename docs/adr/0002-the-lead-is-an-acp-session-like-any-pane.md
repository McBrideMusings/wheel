# ADR-0002: The lead is an ACP session like any pane

The lead is an ACP session started exactly as an agent pane's: the person's Claude configuration (or the daemon's `--agent-config-dir`), every built-in tool, the daemon's `wheel` MCP server, and Wheel's brief appended to its system prompt. The brief, built into wheeld, differs between agents only in the line naming who the agent is. What the lead adds is what its floating card shows: a conversation saved beside the layout, its login, and its saved controls. Every MCP call names its calling session, so a permission request is asked under that agent. The lead and every agent pane use the same transcript and composer. A permission request from any session goes to every attached client, the first answer wins, and no agent answers one.
