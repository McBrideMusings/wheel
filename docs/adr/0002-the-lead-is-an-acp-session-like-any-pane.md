# ADR-0002: The lead is an ACP session like any pane

The lead is an ACP session that the daemon starts with its own Claude config directory, `lead-home/` in the instance directory, so nothing from the person's `~/.claude` reaches it. Its brief and skills live in the repo's `lead/` folder, linked into that directory as its only setting source and appended to Claude Code's standard system prompt. Its built-in tools are Read, Grep and Glob; it changes the app, the spaces and the beads only through the daemon's MCP tools. The lead and every agent pane use the same transcript and composer. A permission request from any session goes to every attached client, the first answer wins, and no agent answers one.
