# ADR-0004: An artifact is its entry in a wheel.toml

An artifact is one `[artifacts.<name>]` table in a `wheel.toml`: a `path`, and optionally a title, a refresh command, an interval in seconds, and whether a pane picker offers it. Nothing beside the page describes it, so a folder of HTML built for any purpose becomes an artifact by being named, wherever it lives. There are two registries: the space's `wheel.toml` (scope `project`) and the instance directory's (scope `machine`, every project on this machine). A bare name means the project's entry, then the machine's. Whether a project commits its `wheel.toml`, or the folders it names, is the project's choice.

`wheel artifact add` writes one entry and `wheel artifact remove` deletes one, and neither touches the artifact's files. `wheel artifact new` also makes a folder with a starter page, under the space's `.wheel/artifacts/` or the instance directory's `artifacts/` unless told where. The daemon's saved state file holds nothing about an artifact beyond the scope and name a web pane carries. An entry that is malformed or contradictory, names a page that is not there, or whose folder holds a `data/` directory, is reported as problems wherever the artifact is listed or shown, and the pane serves whatever its root holds except its own `data/`, which is never served.

Nothing is deleted by default. `wheel artifact new --ends-with-session` writes `ends_with_pane = "<pane>"` into the entry (the agent pane the command ran in, from `WHEEL_PANE`), and `--expires <duration>` writes `expires_at`, the Unix second after which it goes. The daemon checks both when a pane closes, when it starts serving and every 30 seconds, and deletes the entry and its folder. The directories it checks are the open spaces' and a `lifetime-dirs` file in the instance directory, written when an artifact with a lifetime is made, so a space closed before a restart is still swept. It deletes only a folder directly inside the scope's default root (`.wheel/artifacts/` or the instance directory's `artifacts/`), so an artifact registered from anywhere else, or made with `--path`, is never deleted, whatever its entry says.
