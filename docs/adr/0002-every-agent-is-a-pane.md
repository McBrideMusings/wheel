# ADR-0002: Every agent is a pane

An agent is a conversation that an agent pane owns, held by the agent's own program behind wheeld's one agent interface; Wheel runs no agent outside a pane. Each pane names its agent and shows it in its header, and every pane starts the same way whichever agent it runs: the person's own configuration for that agent, every built-in tool, and Wheel's brief added to its instructions. The brief, built into wheeld, differs between panes only in the line naming the pane and its session and the list of artifacts in its space. A permission request from any session goes to every attached client, the first answer wins, and no agent answers one.
