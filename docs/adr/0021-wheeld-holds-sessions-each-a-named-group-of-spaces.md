# ADR-0021: wheeld holds sessions, each a named group of spaces

A session is a named, ordered group of spaces, held by wheeld with the spaces and panes, so every client sees the same sessions. Every space is in exactly one session. A session is created, renamed, reordered and closed through wheeld, and closing it closes its spaces and stops every process in them; a space moves between sessions without stopping anything. A session whose last space closes or moves out closes itself, unless it is the last session or `sessions.close_empty` is off (a session made empty stays until something joins it or someone closes it). A new space joins the session of the pane that asked for it, or the session the request names. Whether a session is shown is each client's business, not wheeld's: wheeld keeps no shown or background flag on a session. `wheel session` lists and changes sessions.
