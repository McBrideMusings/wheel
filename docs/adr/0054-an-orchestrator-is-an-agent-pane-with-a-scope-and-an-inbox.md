# ADR-0054: An orchestrator is an agent pane with a scope and an inbox

This supersedes ADR-0036.

An orchestrator is an agent pane that wheeld gives an inbox and the orchestrator brief. Its scope is a space or global: a space orchestrator is a pane in that space, a global one a pane in the Orchestrator space. It runs like any agent pane, with the person's settings and every tool they allow, and acts on any space or pane through the wheel CLI. Several may share a space. Each agent event goes to one orchestrator: the first started in the agent's space, else the first started global one. A space orchestrator is an agent too, so its own events go to the global orchestrator: space orchestrators report up. The inbox keeps one item per agent and kind until acked, as before, and is in memory. Which orchestrator a person's voice reaches is the client's: the orchestrator pane it shows, else the first global one. ADR-0002's "Wheel runs no agent outside a pane" holds with no exception.

ADR-0002's "no agent answers a permission request" keeps one exception: an orchestrator answers one when what the person said approves or refuses it, and `wheel perm answer` refuses to allow a request that cannot be undone from an orchestrator's pane until it passes `--confirmed`, which its brief says to pass only after the person said yes.

`orchestrator_start` takes the space the pane goes in and the scope, and replies with the pane and its agent; a space orchestrator runs in the `orchestrator.dir` setting of its space, else the space's folder. The pane's kind carries `orchestrator: space|global` and is saved, so a restored pane is an orchestrator again with a new, empty inbox, its place in the start order the order wheeld restores panes in. A reloaded agent keeps its pane's inbox and place. An orchestrator runs only as a chat: its pane refuses the terminal view, where Claude Code would run without the brief. `orchestrator_stop` and the inbox ops name the pane. Until the Orchestrator space exists, `wheel orchestrator start --global` puts the pane in the calling pane's space.
