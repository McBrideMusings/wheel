# ADR-0011: A web pane owns a data directory outside its artifact

Each web pane gets `<instance>/panes/<pane>/`, made when the pane shows an artifact. The pane's URL serves anything under `data/` from that directory, or from the post's folder when the artifact is a post (ADR-0010), and every other path from the artifact's folder, so an artifact's own files stay read-only static content and a pane's generated data never lands in a project's working tree. The directory is keyed by the pane, never by the artifact: one shared artifact open in two projects writes two directories, and two panes on one artifact share nothing. The pane id goes through the same plain-name rule as an artifact name, since a saved layout names it and the directory is made and removed as the pane comes and goes. The pane watches both directories and both send `pane_reload`; closing the pane or changing its kind removes the directory and both watches.
