# ADR-0014: The Mac client owns its windows, and a window shows a session

A Mac window is a main window or a little window, kept in the Mac app's own preferences; wheeld stores no windows and the iPhone has none. A main window shows one session, picked from its title-bar dropdown, and one of that session's spaces at a time; it holds the session's id, the space it shows, an optional name and a sidebar flag, and its tabs and sidebar list the session's spaces in the session's order. A little window shows one space and names the main window it belongs to, or none. A session no main window shows is a background session: its spaces keep running and the menu bar item lists it. Closing a main window asks whether to leave its session running in the background, where the window's little windows stay open and belong to none, or to close the session, which stops every process in it. Nothing but an explicit choice changes which session a window shows, which space it shows or which pane has the keyboard; a new space joins its session without being shown, and a new pane takes no focus. wheel space new --background adds a space to a session without showing it. A `wheel window` command goes to wheeld, which forwards it to the attached Mac app and returns the app's reply; with no Mac app attached the command fails and says so.
