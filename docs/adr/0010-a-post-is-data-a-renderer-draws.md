# ADR-0010: A post is data that another artifact's page draws

An entry may name a `renderer`: another artifact's name, looked up the way a bare name is (the project's entry, then the machine's). Its `path` then names a folder of data, not a page. A pane showing it serves the renderer's folder as its root (ADR-0003) and serves the post's folder under `data/` in place of the pane's own data directory. A post carries no refresh command, and a post whose renderer is missing, or is itself a post, is reported as a problem wherever it is listed or shown. `wheel artifact new <name> --renderer <renderer> <file>…` makes a folder holding only the files given and writes the entry.
