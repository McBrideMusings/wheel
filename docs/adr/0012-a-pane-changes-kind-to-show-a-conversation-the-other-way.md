# ADR-0012: A pane changes kind to show a conversation the other way

An agent's conversation shows either in a terminal pane running the agent's program (`claude`, `codex`) or in an agent pane running it behind wheeld's agent interface, and `pane_view` switches one pane between the two in place; no pane kind holds both. An agent pane carries the agent, the directory and the configuration directory the conversation was written under, so it loads the conversation the terminal wrote. One process holds a conversation at a time: the switch stops the other view's process and waits for it to exit before starting the next, and a switch while a turn is running is refused with the reason.
