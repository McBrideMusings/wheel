# Wheel

A native macOS and iOS agent development environment: one lead agent in a floating card beside a grid of panes (terminals, agent chats, web views), one space per project, all state held by a Rust daemon.

## Layout

- `daemon/` — `wheeld`, the Rust daemon (PTYs, ACP sessions, spaces, permissions, artifacts). Its terminal emulator, `ghostty-vt`, builds libghostty-vt with Zig 0.16: `.cargo/config.toml` points cargo at `tools/zig`, which runs it through `mise` (installed on first use), so cargo needs `mise` on PATH and must run from inside the repo.
- `cli/` — `wheel`, the CLI over the daemon's socket; the programmatic surface every check drives.
- `apple/` — SwiftUI clients: shared `WheelKit` package plus the Mac and iOS apps (Xcode project generated by xcodegen).
- `docs/adr/` — decisions. Read ADR-0001 and ADR-0002 before changing how clients, the daemon or the lead fit together, ADR-0003 before changing what a web pane shows, and ADR-0004 before changing what defines an artifact.
- `DESIGN.md` — layout and visual direction. Early slices use stock macOS styling.

## Tracking

Work is tracked in beads (`bd`, prefix `wheel`). `bd ready` shows what is unblocked.
